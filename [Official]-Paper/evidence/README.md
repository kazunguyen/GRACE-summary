# Evidence cited in the Option 1 drafts

The two table directories contain the original kit CSV exports. The 13 November run reproduced their SHA-256 hashes after the missing validation records were added. See the [validation and export worklog](https://github.com/kazunguyen/GRACE-summary/blob/main/worklogs/2026-11-13_pa1_bo_sung_validation_va_doi_chieu_bang.md) and [independent audit](https://github.com/kazunguyen/GRACE-summary/blob/28405417703f24c594045074bdbe57b8c11a2d5e/worklogs/2026-11-13_pa1_doi_soat_doc_lap_le_anh_duy.md).

- **Table A** includes the ALL-0, ALL-1 and RAND(p) references and supervised anchors. It reports the common 0.5 cutoff and each applicable validation cutoff.
- **Table B** uses Holm adjustment over 18 available comparisons. The drafts use the [PA1 ledger](https://github.com/kazunguyen/GRACE-summary/blob/28405417703f24c594045074bdbe57b8c11a2d5e/Runs-management/analysis_pa1_20261111/full_tables/contrasts.csv), which adjusts over 22 comparisons per threshold policy. H3.1c (B1-H2 versus B1) is exploratory. The kit marks H2.3 and H5.3 as missing. The drafts describe B3 as exploratory and report the actual H5.3 routing comparison separately from the PA1 P_pre/P_post McNemar test.
- **Table C** in the kit uses the common 0.5 cutoff. The drafts report the [PA1 results at the locked B2 cutoffs](https://github.com/kazunguyen/GRACE-summary/blob/28405417703f24c594045074bdbe57b8c11a2d5e/Runs-management/analysis_pa1_20261111/full_tables/sensitivity.csv).
- **Shared threshold.** The JSON records the validation cutoff of P_pre applied to both models and the paired test confidence intervals used in Table D.
- **Historical API runs.** The CSV lists the metrics reproduced in the Step 0 audit for all 36 historical runs. Appendix D also cites the separately reported dev-100 analysis in [§2.1 of the proposal](https://github.com/kazunguyen/GRACE-summary/blob/main/docs/20261111/Option1-De_cuong_nghien_cuu_GRACE_hop_nhat.docx).
